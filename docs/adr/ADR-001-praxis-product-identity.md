# ADR-001: Praxis Product Identity

## Status
Accepted

## Context
Praxis is an operational intelligence platform for field-deployed customer workflow transformation. Its product identity centers on turning messy enterprise signals into executable decision graphs, local proof environments, implementation plans, and measurable value cases.

## Decision
Use Praxis as the repository, product, UI, documentation, and GTM artifact identity.

## Rationale
1. **Field product positioning**: Praxis is a deployable system, not a read-only dashboard
2. **GTM alignment**: Solution packs, value cases, and executive readouts support the full sales cycle
3. **Role coverage**: Maps to Solutions Engineering, GTM Engineering, and Forward Deployed Engineering roles
4. **Ontology-driven**: Palantir-style operational ontology compiler as a core differentiator
5. **FieldLab credibility**: Floci-backed local AWS emulation for customer workflow simulation

## Consequences
- All internal package names updated
- New API routes for fieldlab, solution packs, ontology, value cases, deployment plans
- New frontend pages for Field Workbench, solution packs, executive readout
- Solution-pack system for repeatable GTM demos
- Flagship algorithms: evidence trust, use case scoring, VOI, intervention planner, expansion graph
