# Field Note 003: Identity Onboarding Drift

## Context

Fragmented onboarding ownership leaves a new employee unable to access critical systems.

## Messy Reality

The signal spans ERP roles, Active Directory, GPO groups, print servers, ticketing queues, and manual operator overrides.

## Praxis Mapping

Praxis maps identity governance, access group drift, workflow dependencies, and human approval processes into a deterministic action path.
