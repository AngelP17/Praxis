## Proof-Carrying Platform Rationale

Praxis decisions are not black-box guesses. Every recommendation is accompanied by:
* **The Ingested Event Spine**: A sequence of immutable CloudEvents describing telemetry, tickets, and state changes.
* **The Compiled Ontology Graph**: A deterministic compilation of asset-to-process relationships.
* **The Replay Verification Hash**: A SHA-256 fingerprint proving that re-running the engine over the same event timeline yields identical score vectors and outcomes.
* **The ROI Ledger**: Dynamic value formulations calculating real labor and downtime cost-avoidance in real time.

make praxis-flagship-proof
