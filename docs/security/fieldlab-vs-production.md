# FieldLab vs Production

## FieldLab Mode

- Uses local Floci services
- No customer production credentials
- Synthetic or customer-provided sample data
- Simulated writeback only
- Safe for demos and evaluation

## Production Mode

- Requires customer-approved deployment plan
- Uses configured cloud or on-prem services
- Human-approved actions only by default
- Writeback gated by action policies
- Audit artifacts retained by policy
