# Praxis Positioning

## Product Identity

**Praxis** is a field-deployed operational intelligence system that converts messy customer signals into an executable decision graph, local proof-of-value environment, implementation plan, and measurable business case.

## Tagline

Forward-deployed operational intelligence for messy enterprise workflows.

## One-Line Pitch

Praxis turns customer-specific operational data into executable workflows, explainable decisions, field-ready demos, and measurable implementation plans.

## Core Differentiator

Praxis turns a messy customer problem into:
1. A working demo
2. A decision graph
3. An implementation plan
4. An ROI case
5. An audit trail
6. An expansion strategy

## Target Roles

| Role | How Praxis Serves Them |
|------|----------------------|
| Solutions Engineer | Scope use cases, build demos, explain architecture, handle security/compliance, show business value |
| GTM Engineer | Package repeatable demos, solution templates, ROI calculators, customer narratives, feedback loops |
| Forward Deployed Engineer | Integrate messy customer data, model workflows, build adapters, deploy locally, iterate with users |
| Platform Engineer | Integrate local AWS services to simulate production pipelines without cloud credentials |

## Comparison

| System | What It Is | Praxis Difference |
|--------|-----------|-------------------|
| Dashboard | Shows state | Drives decisions |
| LocalStack | AWS emulation | Customer workflow simulation |
| Palantir Foundry | Enterprise ontology | Independent, portfolio-scale, focused on manufacturing/infra |
| Ticket System | Tracks work | Turns tickets into decision graphs |
