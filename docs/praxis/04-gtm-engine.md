# GTM Engine

## Solution Packs

Solution packs are the GTM centerpiece. Each pack contains:

- **scenario.yaml**: Metadata, systems, signals, metrics
- **customer-context.md**: Industry profile and stakeholder map
- **sample-events.jsonl**: 12+ realistic operational events
- **ontology.yaml**: Pre-built object, link, and action definitions
- **demo-script.md**: 7-minute live demo walkthrough
- **roi-model.yaml**: Configurable ROI variables and formulas
- **objection-handling.md**: Common objections and responses
- **security-review.md**: Compliance alignment and controls
- **implementation-plan.md**: 5-phase deployment roadmap
- **expected-output/**: Reference artifacts for validation
