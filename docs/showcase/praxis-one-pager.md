# Praxis

Praxis is a proof-carrying field deployment system for enterprise operations.

It converts messy customer workflows into operational ontologies, local deployment twins, evidence-ranked decisions, governed human actions, replayable audit trails, and measurable value cases.

## Why It Exists

Dashboards show what happened. Praxis proves what should happen next.

## Core Loop

Customer context -> Ontology -> FieldLab -> Decision -> Action -> Proof -> Value -> Expansion

## Built Systems

- Operational Ontology Compiler
- FieldLab Deployment Twin
- Evidence Trust Scorer
- Value-of-Information Engine
- Intervention Planner
- Expansion Graph
- Proof Object Verifier
- Executive Readout Generator
