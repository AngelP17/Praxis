# Objection Handling

## "We already have tickets."
Praxis does not replace tickets. It turns ticket history, operational signals, and asset context into decision workflows and audit trails.

## "We do not want automation touching production."
Praxis defaults to read-only and human-approval modes. FieldLab writeback is simulated locally through Floci. No automated production changes without explicit approval.

## "Our data is messy."
The Ontology Compiler is designed for partial, inconsistent, and customer-specific data. It reports mapping confidence and asks the next best questions when data is missing.

## "How do we know this creates value?"
Each solution pack produces a value case with assumptions, formulas, confidence, and evidence links. The ROI model uses customer-provided variables.

## "This sounds like consulting."
Praxis provides the technical platform. The solution packs are configurable templates. You own the output. The platform is self-serve after initial onboarding.

## "What about security?"
Praxis generates deployment plans with security reviews, compliance checks, and risk registers. FieldLab runs in an isolated Docker network.
